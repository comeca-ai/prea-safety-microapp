# Preá Safety Training Micro-App Flow

## Onboarding and Sign-In/Sign-Up
A new user arrives at the micro-app by scanning a QR code posted on a sign at Preá beach or by visiting the landing page URL in a mobile browser. The landing page displays a brief introduction and prompts the user to enter their email address. After submitting their email, the user sees a confirmation screen explaining that a magic link has been sent. The user then checks their inbox on the same device, taps the link, and is automatically logged in without needing a password. If the link expires or fails to open, the user can return to the email input screen and request a new magic link. On any authenticated page, the user has access to a sign-out button, which clears their session and returns them to the landing page.

## Main Dashboard or Home Page
Immediately after successful authentication, the user lands on the Dashboard. The Dashboard features a header with the Preá Safety logo, a theme toggle for light and dark modes, and a sign-out button. Below the header, two section cards are displayed side by side on larger screens or stacked on mobile: one card launches the Safety Quiz and the other card launches the Pre-Session Checklist. A navigation link in the header or footer labeled "History" leads to the user’s past activity. The layout adapts seamlessly to mobile, ensuring large tap targets and quick load times even on 4G connections.

## Detailed Feature Flows and Page Transitions
When the user taps the Safety Quiz card, the app transitions to the Quiz page. On this page, each question appears with radio-button options and a progress indicator at the top. The user selects an answer, taps "Next," and immediately sees feedback: a green checkmark for correct answers or a red highlight with an AI-generated explanation for incorrect ones. Once the final question is answered, the user sees a summary screen with their score and an option to retake the quiz or return to the Dashboard. Upon completion, a secure API call records the attempt in Supabase and triggers an n8n workflow for notifications.

If the user selects the Pre-Session Checklist card on the Dashboard, they move to the Checklist page. This screen displays six toggle switches for each safety item. The user walks through the list, toggling each item as they confirm it. At the bottom, a "Complete Checklist" button becomes enabled only after all items are toggled. Tapping this button saves the session to Supabase through an API route and returns the user to the Dashboard with a toast message confirming their checklist has been recorded.

From the Dashboard header, tapping the "History" link takes the user to the History page. Here, the user sees a data table showing past quiz attempts, scores, dates, and checklist completion logs. The table supports sorting by date and score. A back link at the top returns the user to the Dashboard.

## Settings and Account Management
While this micro-app focuses on safety training, users can adjust their theme preference at any time using the theme toggle in the header. They can also sign out by tapping the sign-out icon next to the theme toggle. There is no password management since authentication relies on magic links, but users may re-enter their email on the landing page to regain access if they sign out. The app does not include billing or subscription settings.

## Error States and Alternate Paths
If the user submits an invalid or unrecognized email, the landing page displays a clear error message advising them to try again. During quiz or checklist submission, network failures produce an inline error banner explaining that the save failed and a retry button appears. If authentication fails because a magic link has expired, the app presents a prompt to request a new link. If a database or RLS policy error occurs, a fallback message informs the user of a temporary issue and suggests retrying in a moment. All error messages include guidance on how the user can regain a normal flow.

## Conclusion and Overall App Journey
A user’s journey begins with scanning the QR code or visiting the landing page, signing in via magic link, and arriving at the Dashboard. From there, they can take a quick safety quiz, complete the six-item checklist, and review their history of attempts and completions. Throughout the experience, theme preferences and sign-out options are always accessible. Any errors encountered are handled with clear feedback and easy recovery paths. By following this flow, Preá beach students and instructors receive a fast, mobile-friendly safety training experience that records their engagement and helps maintain consistent safety practices.
